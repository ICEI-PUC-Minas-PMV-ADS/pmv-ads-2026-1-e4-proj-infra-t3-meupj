# Registros de Teste de Sistema

## Requisitos Funcionais

### RF 001 - O sistema deve permitir que o usuário crie uma conta informando nome, CPF/CNPJ, telefone, email, endereço e senha
#### Descrição dos testes
1) Clique no link de "Cadastre-se" na página inicial de login
2) Preenchimento das informações para a criação da conta
3) Após a criação da conta foi feito o login automático
4) Direcionamento para página de configurações e conferência dos dados registrados no login

### RF 002 - O sistema deve permitir que o usuário edite os dados de sua conta
#### Descrição dos testes
1) Login no sistema
2) Direcionamento para página de configurações
3) Alteração do nome da empresa de "Empresa Teste" para "Empresa Teste 2"

### RF 004 - O sistema deve permitir que o usuário cadastre clientes com nome, CPF/CNPJ, telefone, email e endereço
#### Descrição dos testes
1) Login no sistema
2) Direcionamento para página de clientes - Clique no botão "Novo cliente"
3) Preechimento das informações necessárias para cadastrar novo cliente
4) Direcionamento para a listagem com novo cliente adicionado
